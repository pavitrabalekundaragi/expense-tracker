# 💰 Expense Tracker

A simple and user-friendly **Expense Tracker application built using Python**.  
This project allows users to record, view, search, and manage their daily expenses.

The application stores expense data in both **CSV and JSON formats** for easy data management.

## 📌 Features

- ➕ Add new expenses
- 📋 View all expenses
- 💵 Calculate total expenses
- 🔍 Search expenses by category
- 🗑️ Clear all expenses
- 💾 Store data in CSV format
- 📄 Store data in JSON format
- 📅 Automatically records the expense date
- ✅ Simple command-line interface

## 🛠️ Technologies Used

- **Python**
- **CSV**
- **JSON**
- **File Handling**
- **Datetime**
- **Command Line Interface (CLI)**
- **python-project**
- **beginner-project**
